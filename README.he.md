# בדיקת אבטחה לסקילים – Skill Security Audit

**בודקים כל סקיל או פלאגין של Claude לפני שמתקינים אותו.**

[English](README.md)

סקילים ופלאגינים הם כלי חזק. סקיל יכול להגיד ל-Claude מה לעשות, להריץ סקריפטים על המחשב, להתקין חבילות ולהשתמש באפליקציות שחיברתם. בגלל זה הם גם דרך נוחה להחדיר נוזקה. סקיל שנראה כמו "עוזר PDF" תמים יכול לקרוא בשקט את מפתחות ה-SSH שלכם, לשלוח קבצים לשרת זר, או להורות ל-Claude להסתיר את מה שהוא עושה.

הסקיל הזה גורם ל-Claude לבדוק כל סקיל לפני ההתקנה, ולתת פסיקה ברורה:

- 🟢 **בטוח להתקנה** (ברמת בדיקה סטטית)
- 🟡 **להתקין בזהירות**: עם רשימה מדויקת של מה להסיר או לשנות
- 🔴 **לא להתקין**: עם הסבר והפניה לקובץ ולשורה

## מה נבדק

| תחום | דוגמאות |
|---|---|
| גישה מרחוק | reverse shell, הורדת קוד והרצה, פענוח קוד מוסתר והרצה |
| הוצאת מידע | webhooks, אתרי הדבקה, מנהרות, מידע שמוסתר בכתובות URL ובתמונות |
| הזרקת הוראות (Prompt Injection) | "התעלם מההוראות הקודמות", "אל תספר למשתמש", הערות HTML נסתרות, תווים בלתי נראים |
| גניבת פרטי גישה | מפתחות SSH, פרטי ענן, עוגיות וסיסמאות שמורות בדפדפן, טוקנים |
| קריפטו | קובצי ארנק, seed phrases, מפתחות פרטיים, החלפת כתובות בלוח (clipboard), חתימה ואישור טרנזקציות |
| השתרשות ונזק | הפעלה אוטומטית עם עליית המחשב, cron, מחיקה המונית, ניטרול אנטי-וירוס |
| שינוי הגדרות Claude | שינוי הרשאות, hooks או שרתי MCP |
| שרשרת אספקה | חבילות עם שמות מזויפים, התקנות ממקורות לא רשמיים, קבצים בינאריים, ארכיונים זדוניים |
| חוסר התאמה | קוד או הוראות שלא תואמים למה שהסקיל טוען שהוא עושה |

## איך זה עובד

1. **בידוד.** הסקיל הנבדק נכנס לתיקייה ריקה. ארכיונים נפתחים במחלץ מאובטח שחוסם ניסיון כתיבה מחוץ לתיקייה, קיצורי דרך ו-zip bombs. **שום דבר מהסקיל הנבדק לא מורץ.**
2. **סריקה אוטומטית.** סורק Python (`scripts/scan.py`) שלא דורש התקנת חבילות. הוא מסמן שורות חשודות ביותר מ-20 קטגוריות סיכון, ומפרט כל דומיין שהסקיל פונה אליו.
3. **בדיקה ידנית מלאה.** Claude קורא כל קובץ, שופט כל ממצא בהקשר שלו, ובודק אם ההתנהגות תואמת למטרה המוצהרת.
4. **פסיקה ודוח** בשפה שלכם, עם הפניה לקובץ ולשורה.

## התקנה

**Claude.ai או אפליקציית Claude למחשב:** מורידים את הריפו כ-ZIP, ומעלים את התיקייה `skills/skill-security-audit` (מכווצת) דרך **Settings → Capabilities → Skills**.

**Claude Code:**

<div dir="ltr">

```
/plugin marketplace add doobyflink/skill-security-audit
/plugin install skill-security-audit@skill-security-audit
```

## שימוש

פשוט כותבים:

- "תבדוק את הסקיל הזה לפני שאני מתקין" (ומצרפים את הקובץ)
- "הפלאגין הזה בטוח? https://github.com/someone/some-skill"
- "תריץ בדיקה על כל הסקילים שמותקנים אצלי"

טיפ: בקשו מ-Claude לזכור להריץ את הבדיקה על כל סקיל או פלאגין לפני התקנה, ולהריץ אותה שוב על הסקילים המותקנים פעם בחודש.

## מגבלות – חשוב לקרוא

זו **בדיקה סטטית**: הקוד וההוראות נקראים בלי להריץ אותם. הבדיקה מורידה את הסיכון משמעותית, אבל **היא לא מבטיחה שסקיל בטוח**. הסוואה מתוחכמת, תלויות זדוניות ושינויים שנעשו אחרי הבדיקה עלולים לחמוק. התקינו רק ממקורות שאתם סומכים עליהם, ובדקו מחדש אחרי כל עדכון.

הפרויקט מסופק "כמות שהוא" (AS IS), בלי אחריות מכל סוג (ראו [LICENSE](LICENSE)). הוא לא מחליף בדיקת אבטחה מקצועית.
